## Lecture Outline (Time Invariance of Continuous-Time Systems)

### 1. Time Invariance: Main Idea
- A system is **time invariant** if its behavior and characteristics remain fixed over time.
- Intuition:
  - delaying the input should only delay the output
  - the system itself should not behave differently just because the input is applied at a different time

---

### 2. Practical Motivation
- Real systems may not be perfectly time invariant over very long time intervals.
- Example:
  - a capacitor’s capacitance may slowly degrade over time
- But over a short enough time interval, many systems can be treated as approximately time invariant.

---

### 3. Formal Test for Time Invariance
- Suppose:
  $$ x(t) \xrightarrow{\mathcal{T}} y(t) $$
- First method:
  - pass $x(t)$ through the system
  - then delay the output by $t_0$
- This gives:
  $$ y_A(t) = y(t-t_0) $$
- Second method:
  - delay the input first by $t_0$
  - then pass the delayed input through the system
- This gives:
  $$ x(t-t_0) \xrightarrow{\mathcal{T}} y_B(t) $$
- The system is **time invariant** if:
  $$ y_B(t) = y_A(t) = y(t-t_0) $$
  for every input and every shift $t_0$.

---

### 4. Important Perspective
- Time invariance is a property of the **system**, not of the signal.
- The signal can always be shifted.
- The question is whether the system responds in the same way after that shift.

---

### 5. Physical Intuition Example
- Automobile example:
  - applying the same force input in the morning or in the evening should produce the same velocity response, just shifted in time
- If that happens, the automobile model is behaving as a time-invariant system.

---

### 6. Example 1: System $y(t) = \sin(x(t))$
- System rule:
  $$ y(t) = \sin(x(t)) $$
- First path:
  - input $x(t)$ gives output
    $$ y(t) = \sin(x(t)) $$
  - then shift the output:
    $$ y_A(t) = y(t-t_0) = \sin(x(t-t_0)) $$
- Second path:
  - shift the input first:
    $$ x(t-t_0) $$
  - pass it through the system:
    $$ y_B(t) = \sin(x(t-t_0)) $$
- Since:
  $$ y_A(t) = y_B(t) $$
- Conclusion:
  - the system is **time invariant**

---

### 7. Example 2: System $y(t) = t\,x(t)$
- System rule:
  $$ y(t) = t\,x(t) $$
- First path:
  - pass $x(t)$ through the system:
    $$ y(t) = t\,x(t) $$
  - then shift the output:
    $$ y_A(t) = y(t-t_0) = (t-t_0)x(t-t_0) $$
- Second path:
  - shift the input first:
    $$ x(t-t_0) $$
  - then pass it through the system:
    $$ y_B(t) = t\,x(t-t_0) $$
- Compare:
  $$ y_A(t) = (t-t_0)x(t-t_0) $$
  $$ y_B(t) = t\,x(t-t_0) $$
- These are not equal in general:
  $$ (t-t_0)x(t-t_0) \ne t\,x(t-t_0) $$
- Conclusion:
  - the system is **time varying**
  - equivalently, it is **not time invariant**

---

### 8. Why the Second Example Fails
- The system explicitly multiplies the input by the independent variable $t$.
- Because the system rule itself depends directly on time, shifting the input does not simply shift the output.
- This is a common sign that a system is time varying.

---

### 9. General Procedure to Test Time Invariance
To test whether a system is time invariant:

1. Start with:
   $$ x(t) \xrightarrow{\mathcal{T}} y(t) $$
2. Shift the output:
   $$ y_A(t) = y(t-t_0) $$
3. Shift the input first:
   $$ x(t-t_0) \xrightarrow{\mathcal{T}} y_B(t) $$
4. Compare:
   $$ y_A(t) \stackrel{?}{=} y_B(t) $$
5. If they are equal for all inputs and shifts, the system is time invariant.

---

### 10. Main Takeaways
- A system is **time invariant** if delaying the input only delays the output:
  $$ x(t-t_0) \xrightarrow{\mathcal{T}} y(t-t_0) $$
- Example:
  $$ y(t)=\sin(x(t)) $$
  is **time invariant**
- Example:
  $$ y(t)=t\,x(t) $$
  is **time varying**
- The key idea is to compare:
  - shift-after-system
  - versus shift-before-system
